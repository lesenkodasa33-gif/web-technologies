# What The Flexbox?! — Lab 07, Task 2

Проєкт містить самостійно написані HTML/CSS-приклади за темами 20 уроків курсу What The Flexbox?! від Wes Bos.

## Як відкрити
1. Розпакуйте архів.
2. Відкрийте папку `task2` у VS Code або відкрийте `index.html` у браузері.
3. На головній сторінці оберіть потрібний урок.

## Теми
1. Introduction to Flexbox
2. flex-direction
3. flex-wrap
4. ordering
5. justify-content
6. align-items
7. align-content
8. align-self
9. flex property
10. flex-grow, flex-shrink, flex-basis
11. flex-basis
12. flex-basis + wrapping
13. Autoprefixer
14. Flexbox navigation
15. Mobile content reordering
16. Nesting Flexbox
17. Pricing grid
18. Equal-height columns
19. Single-line form
20. Mobile app layout

## Технології
HTML5, CSS3, Flexbox, CSS variables, Google Fonts, media queries.

Примітка: це самостійні навчальні приклади за темами курсу, а не офіційні файли або дослівна копія матеріалів автора.
